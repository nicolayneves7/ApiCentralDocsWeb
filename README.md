# ApiCentralDocsWeb

API para gerenciamento e controle de documentos da plataforma CentralDocs Web. Desenvolvida no contexto acadêmico para prática de desenvolvimento backend, criação de endpoints RESTful e aplicação de padrões de arquitetura.

## Visão Geral

Este projeto foi desenvolvido como parte de atividades acadêmicas com o objetivo de prover a camada de serviços e regra de negócio para a plataforma CentralDocs. A API disponibiliza recursos para autenticação, manipulação, armazenamento e navegação de documentos e usuários.

---

## Funcionalidades

* **Endpoints RESTful:** rotas estruturadas para operações de CRUD (Criar, Ler, Atualizar e Deletar);
* **Gestão de documentos:** disponibilização de serviços para consulta, envio e gerenciamento de arquivos;
* **Autenticação e controle:** preparação de fluxos para validação de credenciais e permissões de acesso;
* **Arquitetura em camadas:** separação clara de responsabilidades entre rotas, controladores e serviços.

---

## Estrutura do Projeto

```text
ApiCentralDocsWeb/
├── Controllers/           # Controladores das rotas e requisições HTTP
├── Models/                # Modelos de dados e representação de entidades
├── Services/              # Regras de negócio e serviços da aplicação
├── Data/                  # Configuração de contexto e persistência de dados
├── Properties/            # Propriedades de inicialização do projeto
└── Program.cs             # Ponto de entrada e configuração do servidor

```

## Tecnologias Utilizadas

## Como Executar

### Pré-requisitos

* SDK da linguagem/framework correspondente instalado;
* Banco de dados configurado (se aplicável);
* Ferramenta de teste de APIs (Postman, Insomnia ou Swagger).

### Passos

1. Clone o repositório:

```bash
git clone [https://github.com/nicolayneves7/ApiCentralDocsWeb.git](https://github.com/nicolayneves7/ApiCentralDocsWeb.git)
cd ApiCentralDocsWeb

```

2. Restaure as dependências:

```bash
dotnet restore

```

3. Execute a aplicação:

```bash
dotnet run

```
